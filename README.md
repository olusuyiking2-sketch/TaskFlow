TaskFlow is a student task management web application that helps users create, organize, track, and complete tasks efficiently.


I built TaskFlow to learn and apply full-stack web development concepts including backend development, authentication, databases, CRUD operations, and web security.

## Technologies I Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2
- Flask-WTF

## Features

- User registration and login
- Secure password hashing
- User sessions
- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by status
- CSRF protection
- Custom error pages
- Responsive glassmorphism UI
